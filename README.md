# Next.js Blog App with Markdown, OAuth, and AI Integration

## Description
This Next.js Blog App which allows users to write, edit, and manage blog posts in Markdown format while offering multiple authentication options, theme customization, and AI-powered assistance for content creation.

## Tech Stack
- **Framework**: Next.js (App Router).
- **Authentication**: NextAuth.js for secure and flexible user authentication.
- **Styling**: Tailwind CSS with ShadCN UI for a responsive and user-friendly design.
- **TypeScript**: Ensuring strong typing and code reliability.
- **State Management**: Zustand for simplified state handling.
- **Validation**: Zod for comprehensive input and schema validation.
- **Data Fetching**: React Query and React Query Mutations for optimized API interactions.
- **Markdown Rendering**: React Markdown for seamless markdown functionality.
- **AI Assistant**: GPT-4 integrated with Next.js via GenAI and custom agents.
- **Database**: Prisma ORM for schema management and data handling.

## Features
- **User Authentication**:
  - Email/Password Sign-Up and Login.
  - OAuth support for Google and GitHub for quick and secure access.
  - Built with **NextAuth.js** for robust and flexible authentication management.
- **Blog Management**:
  - Create, edit, and delete blog posts in Markdown format.
  - Upload Markdown files directly from your computer.
- **Markdown Support**:
  - Real-time rendering with `react-markdown` for a smooth writing experience.
- **Themes**:
  - Light, Dark, and Default modes for a personalized UI experience.
- **AI Integration**:
  - GPT-4-powered AI assistant to help generate and enhance blog content.
- **Optimized State and UI Management**:
  - State management with Zustand.
  - React Query for seamless data fetching and mutation handling.
- **Robust Validation**:
  - Input validation and schema definitions powered by Zod for reliable and error-free operation.
- **Database Management**:
  - Prisma ORM for efficient and scalable database operations.


## To run the application
```bash
cd client
yarn
yarn run dev
```
